Android-приложение для замерщиков и отделочников: объекты, комнаты, проёмы, расход материалов и смета работ — всё считается на устройстве, без сервера.
Репозиторий: [github.com/maks9678/ZamerPro](https://github.com/maks9678/ZamerPro)
---
## Зачем это приложение
На объекте нужно быстро получить цифры: площадь стен под обои/штукатурку, погонные метры откосов, сколько рулонов или смеси заказать и сколько стоит работа. ZamerPro хранит несколько объектов, считает площади по комнатам и сводит материалы и работы к итогам дома.
Это учебный / портфолио-проект: реальный сценарий из стройки, современный Android-стек и локальная база данных.

## Возможности
- **Объекты.** Список домов с датой изменения, создание, поиск по имени, удаление.
- **Комнаты.** Длина, ширина, высота; окна и двери; стандартный или «по стенам» расчёт.
- **Автопересчёт.** Площадь стен с вычетом проёмов, площадь пола/потолка, погонные метры откосов, число окон. Итоги дома обновляются в той же транзакции, что и комната.
- **Материалы.** Справочник с расходом на м² или на погонный метр; привязка к объекту; оценка количества по итогам дома.
- **Работы и смета.** Виды работ с ценой за м², погонный метр или свой множитель; расходники (чеки); сумма по объекту.
- **Навигация объекта.** Нижняя панель: комнаты / материалы / цена — без потери контекста `houseId`.
Модуль визуального планировщика (`tile`) в разработке — в README описан только рабочий контур.

## Архитектура
```
UI (Compose screens)
        │  собирает state, шлёт события
        ▼
ViewModel  ── StateFlow / editor state
        │
        ▼
Repository  (дома; безопасные операции через Result)
        │
        ▼
DAO + Room  ── House, Room, Opening, Material, Work
```
Поток объекта:
1. Список домов → выбранный дом.
2. Вложенный `NavHost`: комнаты, материалы, смета.
3. Экран комнаты сохраняет `Room` + `Opening` атомарно и пересчитывает `totalWallArea`, `totalWindowMetre`, `totalQuantityWindows`.
4. Материалы и работы читают эти итоги и считают расход / стоимость.
Обработка ошибок на уровне репозитория: `Result` (`Success` / `Error` / `Loading`) и `safeCall`.

## Как запустить
```bash
git clone https://github.com/maks9678/ZamerPro.git
```
1. Открыть проект в Android Studio (Giraffe / более новая, с AGP 8.x).
2. Дождаться Gradle Sync.
3. Запустить на эмуляторе или устройстве с Android 7.1+.
Отдельный бэкенд и аккаунт не нужны: данные в локальной Room-базе `zamer_pro_database`.

## Что можно посмотреть в коде
Имеет смысл открыть в этом порядке:
- `MainActivity` — корневая навигация и аргументы маршрутов.
- `HouseDetailsScreen` — вложенный граф и общая `HouseViewModel`.
- `RoomViewModel.saveRoomData()` — транзакция Room + пересчёт итогов дома.
- `HouseRepository` / `Result` — слой данных и безопасные вызовы.
- `MaterialsViewModel` / `PriceViewModel` — реактивный расчёт по `StateFlow`.
